# 페이지 구성 검토

이번 작업은 독립 HTML 시안에 한정합니다. 아래는 다음 구성에 대한 추천이며 현재 메뉴나 기능은 삭제하지 않았습니다.

| 대상 | 추천 구성 | 이유와 보존할 기능 |
| --- | --- | --- |
| 테스트 비교 | 테스트 목록에서 여러 테스트를 선택해 비교 화면으로 이동 | 같은 업무의 다음 동작이므로 독립 메뉴가 없어도 찾기 쉽습니다. 비교 화면과 직접 URL, 데이터셋/설정 차이 경고는 유지합니다. |
| Agent 역할과 분석 지침 | 분석 설정에서 역할별 프로필과 적용 지침을 함께 확인, 지침 버전 편집은 상세로 이동 | 실행 구성을 함께 이해할 수 있습니다. 다시 중첩 탭을 만들지 않고 지침 이력과 공식 평가 및 운영 승인 경로를 유지합니다. |
| vLLM 연결과 LLM 프로필 | LLM 프로필에서 허용 연결 관리로 이동 | 연결 대상 등록과 프로필 생성의 순서를 쉽게 이해할 수 있습니다. 내부 전송 허용 목록과 권한 검사, 삭제 영향 경고는 독립적으로 유지합니다. |
| 실행 상태와 배포 정보 | 현재처럼 실행 상태에서 읽기 전용 배포 상세로 이동 | 자주 확인하는 상태와 기술 설정을 분리할 수 있습니다. 운영 제어 기능을 새로 추가하지 않습니다. |
| 전체 변경 이력 | 연동보다 운영 영역에 배치 | 키뿐 아니라 설정과 승인 이력이 포함되어 있어 운영 업무에 가깝습니다. 분석별 실행 이력과는 구분합니다. |

## 분리 유지

- 운영 설정 평가와 운영 반영 검토: 전자는 현재 평가 조회, 후자는 승인을 수반한 변경입니다. 같은 설정 요약을 공유할 수 있지만 승인 단계를 통계 화면에 숨기지 않습니다.
- 운영 분석과 테스트: 데이터 범위와 키 권한, 실행 목적이 달라 별도 목록을 유지합니다.
- 정답 데이터와 피드백: 정답 승인과 설명에 대한 의견은 다릅니다. 피드백이나 AI 판정을 자동으로 정답에 넣지 않습니다.
- 파서, 입력 스키마, 시그니처 설명: 적용 대상과 검증 계약이 달라 이번에는 합치지 않습니다. 향후 설정 첫 화면에서 연결만 요약할 수 있습니다.

## 이번에 적용한 범위

시간 통계는 새 페이지를 만들지 않고 테스트의 기존 통계 요약에 넣었습니다. 분석 실행 기록 안에서는 왼쪽 단계 선택과 오른쪽 입출력 상세를 연결해 별도 디버그 페이지를 늘리지 않았습니다. 간격은 8/12/16/20/24px 기준으로 맞추되 이미 grid gap이 있는 영역에 margin을 중복 추가하지 않았습니다.
