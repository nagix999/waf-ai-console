# WAF AI Console UI 시안 02

서비스 코드와 분리된 한국어 중심 HTML 와이어프레임입니다. 실제 서비스 API, 데이터베이스나 모델에 연결하지 않습니다.

## 열기

상위 폴더의 **`waf-console-redesign-v2.html`** 파일을 브라우저에서 여세요. 라이브러리와 스타일을 포함한 단일 파일이므로 서버 실행이나 외부 인터넷이 필요하지 않습니다.

이 폴더의 `index.html`도 사용할 수 있지만, 옮길 때는 이 폴더 전체가 필요합니다.

## 구성

- 홈: API 키 별칭별 집계, 판정 분포, 최근 분석과 할 일
- 분석 이력: Production 전용 목록, 필터, 선택 작업과 미리보기
- 운영 분석 상세: 판정, 근거와 입력, 실행 기록, 보고서
- 테스트 분석 상세: 판정과 근거를 왼쪽에, 입력 필드와 payload를 오른쪽에 배치한 통합 화면
- 피드백: 등록 기간과 운영 구성 버전별 집계, 유형별 분포, 분석별 추가형 등록 이력
- 테스트: 목록, 문항별 결과, 3×3 비교 행렬, 그룹 통계와 AND/OR 조건
- 정답 데이터: 편집 중 데이터와 공식 버전 구분, 원문과 라벨 확인
- 설정: LLM 프로필, Agent 역할, 공통 지침, 입력 스키마, 파서와 시그니처 설명
- 연동: Test/Production API 키, 내부 vLLM 대상, API 정의서
- 운영: 실행 상태, 운영 설정 평가, 변경 이력과 읽기 전용 배포 정보

표는 **Tabulator 6.3.1**을 사용합니다. 처음/이전/페이지 번호/다음/끝, 페이지 크기, 정렬과 행 선택을 지원합니다. 상세 검색 조건과 페이지는 URL에 기록됩니다.

색상 버튼은 Light → Dark → SK 순서로 전환합니다. 메뉴는 좁은 화면에서 접히고, 넓은 테이블은 테이블 안에서만 가로 스크롤됩니다.

테스트의 문항별 결과를 열면 `분석 결과 / 실행 / 보고서`로 이동합니다. 분석 결과의 왼쪽과 오른쪽은 각각 스크롤되며, 왼쪽 근거 또는 `원문에서 확인` 버튼을 누르면 오른쪽 payload의 발췌 위치를 강조합니다. 키보드로도 버튼을 선택할 수 있습니다. 선택한 근거는 URL에 남습니다.

원문은 줄바꿈과 특수문자를 바꾸지 않고 텍스트로 표시합니다. 발췌 위치가 불명확하거나 저장된 위치가 원문과 다르면 임의로 강조하지 않고 이유를 표시합니다. payload 외 필드에서 나온 근거는 해당 입력 필드를 강조합니다. 좁은 화면에서는 두 영역을 위아래로 배치합니다. 운영 분석의 기존 탭 구성은 유지합니다.

실행 탭은 왼쪽의 단계 목록에서 하나를 고르면 오른쪽에 해당 기록을 표시합니다. 긴 JSON 두 개를 한꺼번에 배치하지 않고 `출력 / 입력 / 실행 정보`를 전환합니다. 최종 결과 JSON은 별도로 선택하며 역할별 단계 출력과 구분합니다. 선택한 단계와 기록 종류는 URL에 남습니다. 미실행과 실패 및 기록 없음은 완료나 0초로 바꾸지 않습니다.

## 시간 표시

현행 API의 세 필드를 같은 기준으로 사용하며 이 시안의 수치는 모두 예시입니다.

| 표시 | 측정 범위 | 현행 필드 |
| --- | --- | --- |
| 접수→완료 | 서버 접수부터 완료, 큐 대기 포함 | `total_elapsed_ms` |
| 큐 대기 | 서버 접수부터 최초 작업 시작 | `queue_wait_ms` |
| 분석 소요 | 최초 시작부터 완료, 최초 큐 대기 제외 | `processing_duration_ms` |

분석 소요에는 실행 중 대기와 교정 재시도, 복구 간격이 포함됩니다. 순수한 LLM 생성 시간이나 병렬 단계 시간의 합계가 아닙니다. 실패는 `접수→종료`, 진행 중은 `접수→현재`로 구분합니다. HTTP 요청부터 응답까지의 시간은 연결마다 달라 별도 측정해야 하며 이 시안에서는 미측정입니다.

홈과 문항 목록의 시간 표시를 통일하고 기존 통계 요약 안에서 세 시간의 평균, P95 및 유효/미기록 건수를 제공합니다. 평균과 P95에는 완료된 문항 중 기록된 값만 사용하며 미기록은 0초로 간주하지 않습니다. 실패와 처리 중 문항은 완료 통계에 섞지 않습니다. 필터에 따라 표본이 달라지므로 집계 범위도 함께 확인해야 합니다.

## 페이지 구성 검토

페이지를 임의로 삭제하거나 권한이 다른 기능을 합치지 않았습니다. 통합 추천과 유지할 경계는 [페이지 검토](PAGE_REVIEW.md)에 정리했습니다.

## 피드백 집계

피드백 화면은 기본적으로 Production의 최근 30일을 표시합니다. 시작일/종료일, 운영 버전, 용도, 피드백 유형과 검색어를 설정한 뒤 조회하면 집계와 이력 표에 같은 조건을 적용합니다. 최근 7일과 30일 바로가기를 제공하며 조회 조건은 URL에 보존합니다. 날짜의 기준은 분석 접수일이 아니라 피드백 등록일이고, 한국 시간(KST)으로 양쪽 날짜를 모두 포함합니다.

운영 버전은 제품 릴리스나 현재 활성 지침이 아니라 원 분석 실행 당시 고정된 운영 구성 버전입니다. 시안의 두 버전과 각 연결은 예시 데이터에만 명시했습니다. 미기록은 따로 분류하며 Test를 미기록 운영 버전으로 집계하지 않습니다. 등록일 미기록 이력은 기간을 확인할 수 없어 제외 건수를 안내합니다. 과거 기록에 현재 버전을 추정해 넣지 않습니다.

등록 피드백 수, 피드백이 달린 고유 분석 수와 복수 유형 피드백 수를 구분합니다. 유형별 막대는 피드백 한 건 안에서 같은 유형을 한 번만 셉니다. 복수 선택이므로 각 유형 비율의 합계는 100%를 넘을 수 있고, 의견만 있는 이력은 유형 막대에 포함하지 않습니다. 유형과 운영 버전을 누르면 같은 기간의 상세 이력을 좁혀 볼 수 있습니다. 피드백 건수는 모델 정확도나 오류율을 뜻하지 않습니다.

실제 Backend 조회/집계 API와 DB를 구현하거나 운영 버전 필드를 추가한 작업은 아닙니다. 실제 서비스 연결 시 기존 원문 권한, 감사 이력과 운영 구성 스냅샷을 재사용해야 합니다.

## 실제 동작과 시안의 경계

검색, 필터, 정렬, 페이지 이동, 피드백 예시 등록, 참고 라벨 변경과 일부 편집은 브라우저 메모리에서 동작합니다. 새로 열면 변경한 예시 데이터는 초기화됩니다. URL의 필터와 선택한 테마는 유지할 수 있습니다.

모델 호출, 재실행, 실제 PDF/Excel 생성, 운영 반영, API 키 발급이나 삭제, 파서 규칙 생성은 실행하지 않습니다. 관련 버튼은 확인 화면이나 안내만 제공합니다. Markdown 다운로드는 가상 데이터의 텍스트 파일을 생성합니다.

모든 사례와 주소, 수치는 시안용입니다. 보안 판정 기준이나 실제 모델 품질을 뜻하지 않습니다. 피드백은 정답 데이터와 별개이며 AI 판정을 정답으로 자동 사용하지 않습니다. 실제 구현 전환 시 기존 인증, 원문 감사, 운영 승인, API 계약과 서버 평가 지표를 재사용해야 합니다. KR/EN 전체 번역은 실제 React 적용 단계의 보존 항목이며 이 시안은 KR 화면을 구체화합니다.

## 다시 만들기와 확인

```bash
node mockup/console-redesign-v2/build.mjs
node mockup/console-redesign-v2/check.mjs
node mockup/console-redesign-v2/check-split.mjs
node mockup/console-redesign-v2/check-execution.mjs
node mockup/console-redesign-v2/check-feedback.mjs
```

검사 명령은 개발 환경의 Playwright와 Chromium을 사용합니다. 필요하면 `PLAYWRIGHT_MODULE`, `CHROMIUM_PATH`를 지정하세요. 외부 네트워크 요청을 모두 차단하고 단일 HTML 파일의 주요 화면과 동선을 검사합니다. `check-split.mjs`는 양쪽 스크롤, 발췌 강조, 원문 보존과 키보드 조작을 추가로 확인합니다. 검증 캡처와 결과 JSON은 임시 폴더에 생성합니다.

`check-execution.mjs`는 단계 선택과 입출력 분리, URL 유지, 키보드 포커스, 원문의 HTML 안전 표시, 시간 단위와 통계 표본을 확인합니다.

`check-feedback.mjs`는 기간 및 운영 버전 필터, KST 날짜 경계, 복수 유형과 고유 분석 집계, Test 분리, URL 복원과 피드백 상세를 확인합니다.
