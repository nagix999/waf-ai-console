## 안전·집계 검증

- 모든 완료 결과의 framework/provider/model/profile ID/fingerprint가 지정한 실행과 일치했다.
- Verifier가 실행된 각 run에서 Primary와 Verifier의 user input이 동일했다.

- 관리자 Agent 이력 조회는 기존 감사 API를 사용했다. 보고서와 JSON에는 원문 payload, 프롬프트, 모델 설명 본문, 키·쿠키를 내보내지 않았다.
