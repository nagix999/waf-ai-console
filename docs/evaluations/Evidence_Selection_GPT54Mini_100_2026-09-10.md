# 원문 후보 선택 — gpt-5.4-mini 동일 100건 재평가

2026-09-10. 실제 사내 로그 없이 기존 파싱 난이도 50건과 hard 50건을 사용했다. 답안과 데이터 파일은 변경하지 않았다.

참고 답안 일치 **63→81/100**, 전체 보류 **36→15건**. 인용 교정 v2 이전 기준선의 일치는 80/100이었다. 이는 합성 참고 답안 비교이며 운영 정확도가 아니다.

**원문 인용 문제는 개선됐지만 운영 확대를 권할 결과는 아니다.** 정상 답안을 공격으로 판정한 과탐이 **1→6건**으로 늘었다. 일치율·보류율만 개선됐다고 정확도 전반의 개선으로 해석하면 안 된다. 현재 로컬에는 이번 버전을 배포했으며 모델·판정 정책을 임의로 되돌리거나 추가 유료 재평가를 반복하지 않았다.

## 변경 내용

- 모델이 필드명·발췌문을 다시 쓰지 않고 서버의 원문 후보 번호와 해석을 선택한다. 서버는 원문 위치·제출 구간을 재검증한 뒤 기존 결과 형식으로 연결한다.
- 디코딩 해석은 디코딩 전 원문 후보와 연결한다. 변환한 문자열을 원문으로 인정하거나 근거 검증을 완화하지 않았다.
- 공통 시스템 지침은 v2.7로 구분했다. 저장된 관리자 지침 policy-2, 역할별 모델, Verifier 정책, 답안, 입력 필드 정의는 보존했다. 과거 스냅샷은 이전 계약으로 실행한다.
- 새 DB 마이그레이션·운영 패키지·추가 조사 도구는 없다. 기본 Primary 지침은 3,226→3,191자로 바뀌었지만 후보 자료가 추가되어 실제 입력 토큰은 별도 비교한다.

## 남은 오류와 다음 가장 작은 개선

- hard50의 정상 GraphQL 별칭, 정규식 설정, 리터럴 퍼센트 검색어, 화면 경로 문자열, HTML 엔터티 코드 예시, JSON에 인용된 HTTP 요청이 과탐됐다. 뒤의 인용 검사는 통과했지만 문자열이 등장한 위치·용도와 실제 실행 조건의 해석이 잘못될 수 있다는 점을 보여준다.
- 이 6건 중 3건은 직전 두 버전에서 정상 판정, 2건은 보류, 1건은 기존부터 과탐이었다. 단순히 기존 보류를 모두 풀어서 생긴 차이만은 아니다. 새로운 후보 자료와 지침 변화·모델 변동이 함께 있으므로 단일 원인을 입증한 결과는 아니다.
- 과탐 6건 중 2건에는 기존 정책상 Verifier가 실행되지 않았고, 4건은 두 역할 모두 공격으로 판정했다. Verifier를 무조건 추가하는 것만으로 이 오류군이 해결된다고 볼 수 없다. 이번 전체에서는 Primary 78건 일치가 최종 81건으로 바뀌었고, 4건 개선·1건 악화였다. Verifier 단독 또는 미실행 대조 실험은 아니다.
- 파싱 5·35·45·50번은 본문·인증 값 누락, 인자 충돌, Content-Length 충돌을 정상으로 확정했다. 19번은 정상 답안인데 Primary가 보류했다. 이번 전체에서 기대 보류 20건 중 9건을 확정했다. 원문 근거가 있다는 사실과 판정에 필요한 맥락이 충분하다는 판단을 분리해야 한다.
- 다음 최소 범위는 정상 데이터/설정/코드 예시와 실제 실행 입력을 구분하는 맥락 점검을 먼저 오프라인 회귀로 보강하는 것이다. 문항 ID에 따른 예외나 무조건 정상 처리 규칙을 넣지 않는다. 누락·상충 HTTP 구조의 완전성 검사는 별도 축으로 추가 검토한다. 새로운 미사용 문항을 포함한 재평가 범위·비용은 이후 합의한다. 이번 턴에는 이 추가 기능을 구현하지 않았다.

## 기술 검증과 보존

- 100건 모두 같은 역할별 모델·프로필 지문과 v2.7/policy-2 지침을 사용했다. Primary와 Verifier의 실제 입력이 같고 최상위 평가 메타데이터가 모델 이벤트에 들어가지 않았음을 검사했다.
- 선택 원문 검사 이력 194개 역할 실행을 확인했다. 전체 선택 출처 연결 551건, 원문 교정 0회다. 번호·문자열·위치 검사 통과가 해석의 의미적 정확성을 보장하지 않는다.
- 구조화 출력 추가 시도 0회. 오류 유형: {}.
- 전체 회귀 1,675항목에서 정의서 사본 불일치와 이전 계약을 반환하던 시간 측정 모의 응답 2항목을 보완했다. 최종 관련 127항목 통과 및 추가 1항목을 포함해 총 1,676항목을 검증했다. 새 후보 선택 테스트는 29항목이다. 실제 네트워크 호출 없는 테스트이며 Starlette/AnyIO의 기존 폐기 예정 경고가 남는다.
- 백엔드 세 서비스만 재배포했다. 기존 프런트엔드 이미지·컨테이너는 유지하고 API 내부 주소 갱신을 위해 nginx를 reload했다. 기존 639건·키·관리자 지침·필드 정의·암호화 이력은 백업 및 행 지문 대조로 보존을 확인했다. 이번 테스트 100건과 관련 이력만 추가했다.
- OpenAI 공식 [구조화 출력 규격](https://developers.openai.com/api/docs/guides/structured-outputs)의 필수 필드·추가 필드 금지 조건은 기존 공용 스키마 변환기로 적용했다. 두 provider의 실제 ModuAgent 직렬화는 HTTP 모의 응답으로 검증했다.

## 한계

- 동일 데이터는 개발 과정에도 사용했으므로 미사용 독립 평가셋이 아니다. 합성 답안 자체의 타당성, 모델 변동성과 한 번 실행의 우연성을 분리해 입증한 실험도 아니다.
