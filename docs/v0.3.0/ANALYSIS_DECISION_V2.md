# 판정 결과 상세 v2

2026-09-29. 시작 커밋 `de788c4`. 사용자가 제공한 `waf_analysis_result_wireframe_v2.html`과 변경 표를 기준으로 상세 화면을 개편했습니다. 이번 요청에서 지정한 4개 탭이 기존 R5의 상세 5개 탭 구성을 대체하며, 나머지 운영 보호·평가·접근 제약은 유지합니다.

## 변경 내용

- 상단은 판정·심각도·핵심 요약과 WAF 조치·전체 소요 시간·입력 생략·용도로 구성합니다. 요약 본문과 큰 페이지 제목을 중복 표시하지 않습니다.
- 기본 탭은 **판정 / 근거·입력 / 실행 / 보고서**입니다. 기존 result/raw/agent/report URL을 유지하고 json 링크는 실행 탭의 결과 JSON을 펼쳐 표시합니다. 테스트 문항에서 크게 보기와 뒤로 가기도 유지합니다.
- 판정 탭은 근거를 먼저 보여줍니다. 정탐·오탐 방향과 서로 다른 해석은 보존하고, 참고 내용과 기술 해석·상충 정황·해석 한계는 접어 둡니다. 구분 없는 과거 근거를 임의 분류하지 않습니다.
- 판단 쟁점과 추가 확인은 하나의 영역에서 봅니다. 동일하게 기록된 조건·확인 문구는 한 항목으로 연결하고, 출처·확인 목적·관련 근거를 보존합니다. 의미가 비슷하다는 추정만으로 서로 다른 문장을 삭제하지 않습니다. 확정 판정의 후속 확인을 모두 재판정의 필수 조건으로 표현하지 않습니다.
- 우측 판정 맥락에 1차/심층 판정과 참고 라벨 비교·입력·이력을 배치합니다. 수집기 점수와 심층 판정 점수를 같은 확률로 비교하지 않습니다. 정책 검토 제안은 접힌 작은 영역입니다.
- 근거·입력에서는 근거 목록과 기존 HTTP/입력 필드/디코딩 열람기를 함께 봅니다. 발췌와 동일한 문자열만 찾으며 디코딩 결과를 원문처럼 강조하지 않습니다. HTTP 전체 검색은 해당 필드의 위치를 다시 검증했다는 뜻이 아님을 표시합니다.
- 실행은 고정 모델·지침·스키마·시간과 단계 요약을 먼저 보여주고, 전체 단계 디버거와 결과 JSON은 사용자가 펼쳐 봅니다. 단계 선택·원문 보기 상태는 탭 왕복 시 보존합니다.
- 테스트 문항 미리보기에도 공통 확인 조건 표시를 사용합니다. 기존 보고서 미리보기/Markdown/PDF/Excel, 실패 재실행 확인 창은 유지합니다.

## 와이어프레임과 조정한 부분

- 예시 데이터·판정 전환 버튼·가상의 처리시간/호출 수는 넣지 않았습니다. 현재 결과 API가 전체 요청의 완전성을 보장하지 않으므로 Hero의 입력 상태는 **입력 생략**으로 표시하고, 기록이 없으면 미기록으로 둡니다.
- 심각도와 최종 판정은 저장된 값을 사용합니다. UI가 판정을 고치거나 근거 강도를 새로 계산하지 않습니다.
- 재분석 버튼은 기존 계약대로 실패한 분석의 재실행만 제공합니다. 완료된 분석을 임의로 새 모델 호출하는 기능은 추가하지 않았습니다.
- 보고서 내용 생성기와 PDF/Excel 계약은 변경하지 않았습니다. 화면 배치를 개편하기 위해 저장된 보고서 이력을 다시 쓰지 않습니다.

## 보존·변경 범위

Backend/DB migration/API/Agent/운영 설정 변경 없음. 새 패키지나 운영 Chromium 의존성 없음. 원문·Agent 이력은 기존 관리자 API로 명시적 열람 시 조회하며 감사 정책을 유지합니다. 탭에 키보드 포커스만 옮기는 것으로 조회하지 않습니다. 원문·발췌를 URL, localStorage, sessionStorage에 넣지 않고, 다른 분석의 늦은 응답은 무시합니다.

Docker 재배포·Git commit/push·실제 모델 호출·운영 데이터 조회는 수행하지 않았습니다.

## 검증

- 프런트엔드 단위/렌더링 회귀: 502건 통과.
- Vite production build 통과. 기존 단일 JS 번들 500kB 초과 경고는 남아 있습니다.
- `analysis-decision-smoke.mjs`: 실제 React + 가상 API, 외부 통신 차단. 4개 탭, 근거/원문 연결·조회 오류 복구, 늦은 응답 격리, JSON 이전 링크, 단계 선택 보존, 참고 라벨 저장, PDF/Excel 다운로드 요청, 실패 재실행 확인 창, 키보드 포커스 검증.
- 정탐/오탐/보류/실패/대기, SK/Light/Dark, 주요 KR/EN 화면, 1440/390 및 360/768/1024 폭에서 스크린샷 50개 생성. 주요 데스크톱·모바일·근거 화면을 직접 시각 검토했습니다.
- `r5-final-smoke.mjs`: 공식 테스트·운영 반영 차단·정답 데이터·원래 버전 복제·테스트 문항 뒤로 가기 회귀 통과.
- `responsive-ui-smoke.mjs`: 전체 메뉴·주요 상세·폼의 브라우저/모바일 회귀 통과. 157개 스크린샷을 다시 생성했고 페이지 가로 넘침·버튼 간격·표 정렬·헤더 동작 검사를 통과했습니다.
- Backend와 DB를 변경하지 않아 backend 전체 테스트·migration은 재실행하지 않았습니다. 브라우저 다운로드 검사는 요청 옵션과 클라이언트 저장 동작의 가상 응답 검사이며 실제 PDF 렌더러 재검증을 뜻하지 않습니다.

실제 운영 데이터·LLM·배포 API와의 E2E, 실물 모바일/Safari/스크린리더 전수 검증은 하지 않았습니다. 기존 상세 도구·모델 생성 본문의 한국어 전용 문구 일부는 그대로입니다.
