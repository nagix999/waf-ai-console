# Desktop / mobile UI review

기준: `feature/canonical-r5-final`, 시작 커밋 `4ae440c`.
기존 R5 구현 위에서 화면 표현과 탐색을 보완했습니다. Backend, API 계약, DB migration, 운영 설정, 비밀 값은 변경하지 않았습니다.

## 변경 사항

- 로고와 상단 바를 같은 64px 기준으로 정렬했습니다. 데스크톱은 검색·계정 접근을 위해 상단 바만 고정합니다. 모바일은 두 줄짜리 헤더를 고정하지 않아 읽을 공간을 확보합니다.
- `NavigationAction`으로 다른 화면을 여는 버튼·링크를 통일했습니다. 이동 경로는 연한 녹색, 일반 저장·실행은 기존 중립색, 운영 반영은 브랜드색, 주의·삭제는 기존 의미 색을 유지합니다.
- 붙어 있던 기본 테스트 설정/새 테스트 버튼을 분리하고, 테스트 목록의 이동·생성 버튼을 한 줄의 도구 영역으로 묶었습니다.
- 표의 외곽 여백, 행의 세로 정렬, 숫자 열의 헤더/값 우측 정렬, 검색 필드 폭을 정리했습니다. 넓은 표는 내부에서 가로 스크롤하며 모바일 페이지 자체는 넘치지 않습니다. 많은 평가 지표를 펼친 표는 충분한 최소 폭을 유지합니다.
- 표의 더보기 메뉴를 별도 레이어에 표시해 스크롤 영역에 잘리지 않도록 했습니다. 메뉴 위치 보정, Escape 닫기, 원래 버튼으로 포커스 복귀를 유지합니다. 모달 내부 메뉴는 해당 모달 안에 남습니다.
- 모바일 평가 행렬, 1차/심층 판정 비교, 테스트 설정 폼을 재배치했습니다. 평가 일치/오류 방향은 색뿐 아니라 기존 문구로도 구분합니다.
- 홈의 운영 구성은 데스크톱 2열로 압축하고, 내용이 적은 카드는 불필요하게 늘어나지 않게 했습니다. 차트는 실제 표시 폭에 맞춰 좌표를 계산하므로 모바일에서도 축 글자가 작아지지 않습니다.
- 정답 데이터 상세 높이를 제한하고, 작은 화면에서 문항을 선택하면 상세로 이동합니다. 저장·복원 버튼 간격을 확보했습니다.
- 모델 편집 폼의 중복 제목, 과밀한 열 배치, 운영 역할 변경에 관한 오래된 안내를 정리했습니다. 공식 테스트 → 운영 반영 검토 → 운영에 반영 경로는 그대로입니다.

## 검증

- 프런트엔드 단위/렌더링 테스트: **489건 통과**.
- Vite production build: 통과. 기존 단일 JS 번들의 500kB 경고는 남아 있습니다.
- `r5-final-smoke.mjs`: SK/Light/Dark × KR/EN, 공식 평가/기본 설정/버전 고정 복제/가져오기/운영 반영 차단 조건/뒤로 가기/포커스 회귀 통과.
- `responsive-ui-smoke.mjs`: 데스크톱 1440px, 모바일 390px 전체 메뉴와 주요 상세·팝업 확인. 360/768/1024px 추가 폭 확인. 핵심 화면의 테마·언어 조합까지 159개 스크린샷 생성 및 페이지 가로 넘침 검사.
- 포털 메뉴 위치, Escape 포커스 복귀, 숫자 열 정렬, 작업 버튼 간격, 데스크톱 구분선 및 스크롤 고정, 모바일 비고정, 키보드 포커스를 검사합니다.
- 스크린샷 모음과 주요 화면 원본을 검토하고 수정 후 다시 촬영했습니다.

## 확인 범위와 제한

브라우저 검사는 **실제 React 코드 + 합성 API 응답**을 사용합니다. 운영 API, 실제 내부 로그, 유료 LLM을 호출하지 않았습니다. 모바일은 Chromium의 화면 크기 에뮬레이션이며 실물 iOS Safari/Android 기기 검증은 아닙니다. 기존 일부 설정 화면과 분석 본문의 한국어 전용 문구는 남아 있습니다.

Backend/DB 변경이 없어 이번 UI 작업에서는 backend 전체 테스트와 migration을 재실행하지 않았습니다. 배포·Git commit/push는 하지 않았습니다. 개발용 브라우저를 검사에만 사용하며, 운영 이미지에 Chromium이나 다른 라이브러리를 추가하지 않습니다.

## 다시 실행하기

Node.js 24 환경과 개발 머신에 이미 설치된 Playwright/Chromium을 사용합니다. 스크립트는 브라우저를 자동 다운로드하지 않습니다. 다른 설치 경로는 `PLAYWRIGHT_MODULE`, `CHROMIUM_PATH`로 지정할 수 있습니다.

```bash
cd frontend
node --test --test-isolation=none src/*.test.mjs
npm run build
node scripts/r5-final-smoke.mjs
node scripts/responsive-ui-smoke.mjs
node scripts/screenshot-review.mjs
```

스크린샷은 저장소에서 제외된 `test-results/responsive-ui/after/`에 있습니다. `index.html`에서 전체 이미지를 열 수 있고, `audit.json`에서 화면 폭 검사 결과를 확인할 수 있습니다. 수정 전 비교 자료는 `test-results/responsive-ui/before/`입니다.
