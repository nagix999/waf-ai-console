# 브라우저 탐색 및 목록 복원

기준일: 2026-09-08. 프런트엔드 코드·테스트 변경이며 실행 중인 Docker에는 미배포 상태다.

## 변경 내용

기존 화면 전환은 React의 `page` 상태만 변경했고 Production API 진입도 `replaceState`만 사용했다. 브라우저에 이전 화면 기록이 없고 `popstate`도 처리하지 않아 뒤로 가기를 사용할 수 없었다.

이제 화면 이동을 History API에 추가하고 `popstate`/`hashchange`에서 해당 화면을 복원한다. 같은 화면 재클릭과 검색 입력·적용·페이지 변경은 불필요한 방문 이력을 추가하지 않는다. 검색과 페이지는 해당 이력의 메모리 스냅샷을 갱신한다.

지원 범위:

- 대시보드·분석 결과·테스트 분석·Production API·설정 메뉴 왕복.
- 전체/테스트/프로덕션 구분 및 테스트 전체 문항 목록.
- 프로덕션 검색 목록 → 분석 상세 → 검색·페이지 복원.
- 테스트명 검색 목록 → 실행 결과 → 문항 상세 → 평가 범위·선택 셀·문항 페이지·테스트명 검색 복원.
- 설정의 모델·프롬프트·입력 스키마·Internal Egress·서비스 키 탭.
- 분석 상세의 판정 결과·HTTP 원문·보고서 탭.
- 대시보드에서 상세를 연 경우 화면의 복귀 버튼도 실제 출발 대시보드로 이동.
- 직접 상세 주소를 열었을 때는 화면의 복귀 버튼이 외부 페이지로 나가지 않고 기본 분석 목록으로 이동.

브라우저 뒤로 가기는 실제 방문 순서를 따른다. 화면의 ‘테스트 목록’ 등 이름 있는 복귀 버튼은 같은 문서의 해당 상위 화면을 찾아 복귀하며, 이력이 없으면 명시된 목록으로 이동한다. 접근성 ‘본문으로 이동’은 화면 경로를 바꾸거나 탐색 이력을 추가하지 않는다.

## 주소와 개인정보 경계

| 화면 | 해시 주소 |
| --- | --- |
| 대시보드 | `#dashboard` |
| 전체 / 프로덕션 | `#analyses` / `#analyses/production` |
| 테스트 실행 목록 / 전체 문항 | `#analyses/test` / `#analyses/test/items` |
| 테스트 실행 결과 | `#test-runs/{서버 UUID}` |
| 분석 상세 / HTTP 원문 / 보고서 | `#analyses/{서버 UUID}`와 선택적 `/raw`, `/report` |
| 테스트 입력 | `#test` |
| 설정 | `#settings/models`, `/prompts`, `/schema`, `/egress`, `/keys` |
| 기존 Production 문서 링크 | `#production-api` |

사용자 검색어·회사/IP·Source System·테스트명·원문·키·API 응답을 URL에 넣지 않는다. UUID는 인증 수단이 아니며 직접 주소를 열어도 기존 세션·권한 검사를 거친다. 잘못된 UUID나 임의 문자열은 API 조회 식별자로 사용하지 않는다.

`history.state`에는 문서·로그인 구간·항목을 구분하는 불투명 토큰만 기록한다. 목록 검색값은 현재 문서의 메모리에만 존재하며 localStorage/sessionStorage에 저장하지 않는다. 기존 테마 저장 정책은 변경하지 않는다. 로그아웃이나 상위 화면의 인증 만료 처리 시 메모리 이력을 폐기한다. 이후 브라우저 Back/Forward는 이전 검색값이나 인증된 화면 데이터를 복원하지 않는다.

최근 200개 화면 이력까지만 스냅샷을 보관한다. 새로고침·새 탭·이전 로그인 구간·범위 초과 이력은 주소로 화면만 복원하고 검색값은 기본값으로 초기화한다. 전체 원문, 모델/프롬프트/스키마 편집 초안, 업로드 파일, 발급된 API Key를 화면 복귀용으로 보존하지 않는다. 세부 펼침 상태·스크롤 위치의 정확한 복원은 이번 계약이 아니다.

## 검증 및 배포

- 프런트엔드 전체 회귀 파일 통과, Vite Production 빌드 성공.
- 경로 파싱·직렬화·민감값 제외·복귀 대상 6개와 History controller 19개 단위 테스트 통과.
- 합성 Chromium 브라우저 9개 시나리오 통과: 메뉴 왕복, Production 검색·페이지·원문 탭, 테스트의 Back 2회/Forward 2회, 설정 탭, 대시보드 복귀, 이전 테스트 실행과 Production 복귀 경로 격리, 직접 보고서 주소·새로고침·안전한 기본 복귀, 접근성 링크, 로그아웃·재로그인 시 검색 초기화.
- 브라우저의 모든 API를 합성 응답으로 가로챘다. 예상 밖 API 쓰기·조회 및 외부 요청은 차단하고 검사 실패로 처리한다. 운영 API·실제 LLM·GPU는 호출하지 않았다.

브라우저 스크립트는 `frontend/scripts/navigation-smoke.mjs`다. 기존 Playwright·Chromium 설치를 사용하며 패키지나 브라우저를 자동 설치하지 않는다. 운영과 다른 `127.0.0.1:15173` 임시 Vite 서버에서 실행한다. 새 운영 의존성, DB migration, API 계약 변경은 없다. Firefox/Safari 및 배포 UI 검증은 하지 않았다.
