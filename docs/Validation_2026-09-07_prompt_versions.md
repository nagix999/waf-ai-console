# 통합 테스트·분석가 표현·프롬프트 버전 관리 검증

기준일: 2026-09-07. 사용자가 합의한 통합 테스트 화면, 결과·보고서의 업무 용어와 작성 지침 개선, 프롬프트 저장·복제·비교·운영 적용·복귀 범위를 구현했다. 후보 프롬프트 실행·자동 평가는 포함하지 않는다.

## 구현

- 테스트 분석 메뉴의 직접 입력/파일 업로드 탭. 입력 전환 시 값·선택 파일·접수 결과 보존, 기존 테스트 API·유입 분류·업로드 오류·분석 링크 유지.
- 판정 요약 → 세부 분석 → 판정 근거 → 기타 → 추가 확인 사항 순서 유지. 화면과 Markdown 보고서의 용어 통일 및 빈 정황·정책 제안 생략. 실제 위험·제한 설명과 서로 다른 근거 해석은 보존.
- 원문 위치의 한국어 이름과 정확한 필드 경로 병기. bare `query`/`headers.*` 같은 이벤트 필드를 HTTP 하위 필드로 추정해 표시하지 않음.
- 현재 코드 프롬프트 `waf-judgment-v2.5`. 고정 규칙과 판정·작성 지침 분리, 요약·동작과 영향 조건·시그니처 비교·개별 근거의 역할 구분.
- 관리자 전용 불변 정책 버전과 암호화 저장, 작성자·시각·변경 설명·지문·부모 버전, 단일 활성 선택과 revision 충돌 검사.
- 새 접수의 전체 지침 암호화 스냅샷 고정, 독립 Verifier·교정 Retry 기본 지침·재선점 유지, 과거 결과 보존. 손상된 신규 스냅샷을 legacy로 오인해 최신 지침으로 대체하지 않음.
- 정책 길이를 반영한 입력 여유, 현재 Production에서 최소 입력 공간조차 부족한 운영 적용 차단. 실제 tokenizer 한도 검증은 아님.

수명주기·초기 기본 지침 등록·관리자 API·마이그레이션 절차는 [프롬프트 버전 관리 정의서](Prompt_Policies_v0.1.md)에 기록했다. OpenAI Docs 스킬의 [공식 프롬프트 가이드](https://developers.openai.com/api/docs/guides/prompt-engineering)를 참고해 작성 지침과 별도 품질 평가를 구분했다. 저장·형식 확인·운영 적용만으로 품질 검증 완료를 표시하지 않는다.

## 오프라인 검증

| 검증 | 결과 |
| --- | --- |
| 전체 backend pytest | **867 passed**, 164.88초, 기존 Starlette/AnyIO deprecation 경고 1개 |
| 전체 frontend Node 22 테스트 | **120 passed**, 실패·건너뜀 0 |
| Vite production build | 통과, 48 modules |
| 통합 테스트·분석 상세·보고서 모의 Chromium | 통과 |
| 프롬프트 설정 모의 Chromium | 통과 |

백엔드는 운영 볼륨 없이 저장소를 읽기 전용으로 마운트하고 네트워크를 차단한 테스트 컨테이너에서 실행했다. 프런트 테스트도 Node 22 네트워크 차단 컨테이너를 사용했다.

새 테스트는 다음을 포함한다.

- 서비스 키·미인증 접근 차단, 입력 길이·제어 문자·유효 Unicode, 오류 본문 비노출
- 암호화/내용 지문 검증, 불변 저장 API, 저장과 활성화 분리, 명시 동의, 동시 활성 변경 409
- 동시 기본 정책 초기화와 호출자 transaction rollback 보존
- 정책 변경 후 이전 접수·중복 접수·Primary/Verifier·lease 재선점의 같은 기본 지침 유지
- 신규 스냅샷 손상·이중 컬럼 누락 시 호출 전 차단, 실제 legacy 선택 시점 구분
- 짧은 모델 컨텍스트에서 호출 전 실패, 불가능한 활성화 거부와 이전 선택/revision 보존
- `0006`의 합성 기존 분석·연결 이력 보존, nullable FK·무결성 검사, 데이터 있는 downgrade 거부

마이그레이션 검증은 합성 DB를 사용한 비교이며 운영 DB에 실제 마이그레이션을 수행했다는 뜻은 아니다.

## 브라우저 검증

별도 `127.0.0.1:18081` 개발 서버에서 모든 API 요청을 모의 응답으로 가로채고 외부 origin 요청을 차단했다. 운영 서비스 `18080`은 사용하지 않았다.

- 두 입력 탭의 작성값·선택 파일·접수 결과 보존과 기존 test API 호출, 결과 이동
- 상세/보고서 순서와 업무 용어, 실제 필드 경로, 빈 카드 생략, 추가 확인 마지막 배치
- 원문/디코딩 지연 조회, HTML 비실행, 390px 다크 화면 가로 넘침 없음
- 버전 복제·4,000자 초과 차단·텍스트 비교, 저장만으로 운영 버전이 바뀌지 않음
- 매번 명시 동의 후 적용, 409 시 재조회만 수행하고 재동의 없이 재전송하지 않음
- 이전 저장 버전으로 복귀 후 전체 버전 보존, 본문/고정 규칙의 HTML 비실행

테스트용 개발 서버는 검증 후 종료했다. 스모크 스크립트와 캡처는 임시 `/tmp` 산출물이며 운영 파일·실제 WAF 로그를 포함하지 않는다.

## 미실행·후속 단계

- 실제 vLLM/OpenAI 호출, 실제 사내 로그 전송, 유료 검증은 **수행하지 않았다**.
- 실행 중인 기존 Docker 서비스·운영 DB·모델 프로필·비밀번호는 변경하지 않았다.
- 새 문체의 품질, 의미상 근거 중복 감소, 인용 정확성, 모델별 실제 토큰 한도는 미검증이다.
- 다음 단계는 기존 실행 상태 확인·SQLite 일관성 백업 후 `0006_prompt_policies`와 같은 버전 API/worker/frontend를 재배포하는 것이다. 그다음 별도 합의한 합성 소수 표본으로 실모델 출력을 검토할 수 있다.
