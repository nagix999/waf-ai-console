# 분석 결과 통합 및 Docker 재배포 검증

기준일: 2026-09-07. 사용자 승인에 따라 분석·평가 보기 통합과 Docker 재배포를 수행했다. 앞서 구현한 통합 테스트 화면·분석가 표현 개선·프롬프트 버전 관리도 이번 이미지에 포함했다.

## 화면 변경

- 보기 전환 없이 6열: 판정·심각도 / 이벤트·요약 / 회사·연결 / 참고 답안 비교 / 전체 소요 시간 / 접수 시각.
- WAF 열과 반복 완료 배지를 제거하되 WAF 상세·필터·저장 값은 유지한다. 상태별 배경은 대기=회색, 처리=옅은 파랑, 실패=옅은 붉은색, 완료=기본색이며 아이콘·문구를 병기한다. 완료된 보류나 답안 불일치는 처리 실패가 아니다.
- 참고 답안 비교는 기준값과 일치·다름·판정 보류·평가 대기·제외를 표시한다. 명시적인 미라벨만 대시로 표시하고 정보 누락·조회 오류를 별도로 구분한다. 합성 기대값·지원 판정·열람 미확인과 제외 사유는 보존한다.
- 답안 연결 상단 버튼, 접힌 검색 범위 전체 비교 집계, 상시 접근 가능한 답안 필터와 적용조건 해제 태그를 제공한다. 필터 태그의 로컬 날짜와 API 쿼리는 같은 시각을 사용한다.
- 상세 평가 탭을 제거하고 판정 요약 아래에 참고 답안 비교를 넣는다. AI 최종 판정을 다시 반복하지 않으며 출처·연결 이력은 펼쳐 확인한다. 답안이 없는 경우 숨기되 이력 조회 오류는 노출한다.
- 혼합 범위에서만 목적 배지를 반복 표시한다. 접수 날짜/시간을 두 줄로 나누고 진행 시간은 ‘경과’로 표시한다. 긴 회사/IP는 전체 텍스트와 title을 보존하고 이전 심각도·모의 실행 안내는 셀 안에서 줄바꿈한다.

화면 통합 자체의 API·DB·LLM 호출 정책 변경은 없다. 기존 HTTP 원문·Agent 입출력 지연 조회와 감사 정책, 추가 확인 마지막 순서를 유지한다.

브라우저 스크립트·캡처는 `/tmp/waf-unified-browser.cjs`, `/tmp/waf-unified-*.png`의 임시 합성 산출물이며 배포 데이터에 저장하지 않았다.

## 실제 배포와 데이터 보존

기존 frontend/API 접수를 중지하고 활성 분석·모델 테스트 0건을 확인한 뒤 두 worker를 중지했다. SQLite backup API로 스키마 0005의 현재 DB를 백업하고 무결성을 검사했다. 백업은 기존 볼륨과 비공개 호스트 경로에 모두 보관한다.

- 활성 구성: `.local-deploy/unified-analysis-v25/compose.json` (비밀 포함, 출력·공유 금지).
- 배포 전 백업: `.local-deploy/unified-analysis-v25/pre-20260907T053716Z.db` (600 권한).
- backend: `waf-ai-console-api:deploy-20260907T053716Z`, image ID `491d1642e2cd6a29151e04a52dd59790f1e066281b9e1bdcc67d48ba4aaeefd1`.
- frontend: `waf-ai-console-frontend:deploy-20260907T053716Z`, image ID `195f5c96b91a12a36de28ce84fa9b43d395e8ce315542aff6737315e9b4e1402`.
- 최종 정적 자산: `index-DTnpPIjf.js`, `index-C8Jt3f5X.css`.
- API·두 worker·frontend 모두 기존 환경 지문 일치, 기존 암호화·인증 값과 역할·포트·볼륨 보존. API healthy, worker 역할별 `moduagent` 시작 확인, 재시작 횟수 0.
- UI `http://127.0.0.1:18080`, API `http://127.0.0.1:18000` 유지.

네트워크 차단 새 backend 이미지로 `0005_analysis_labels → 0006_prompt_policies`를 적용했다. 백업의 기존 컬럼 전체를 기준으로 모든 기존 행을 대조해 내용 보존을 확인했고, DB integrity 및 foreign key 검사도 통과했다. 최초 검증 시 읽기 전용 볼륨에서 WAL 보조 파일을 생성하지 못해 `SQLITE_CANTOPEN`이 발생했다. 볼륨의 보조 파일 접근만 허용하고 DB 연결은 `mode=ro`로 유지해 다시 검사했으며 애플리케이션 데이터를 수정하지 않았다.

## 미검증·복구 주의

- 실제 vLLM/OpenAI 호출, 유료 API 검증, 실제 로그 외부 전송은 수행하지 않았다. 이번 결과는 실모델 품질·GPU 연결 성공을 보증하지 않는다.
- 프롬프트 v2.5의 실제 문체·의미상 반복·토큰 한도는 별도 합성 실모델 검증이 필요하다.
- 백업 복원 자체는 실행하지 않았다. 0006 이전으로 복귀하려면 신규 쓰기를 멈추고 이후 데이터 유무를 확인한 뒤 호환 이미지와 이번 0005 백업을 함께 검토해야 한다. 이전 이미지만 올리거나 자동 downgrade를 실행하지 않는다.
- 안전한 현재 기동 명령과 복구 주의사항은 `.local-deploy/README.md`, 프롬프트 동작은 [프롬프트 버전 관리 정의서](Prompt_Policies_v0.1.md)를 참고한다.
