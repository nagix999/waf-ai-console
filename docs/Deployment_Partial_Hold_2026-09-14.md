# 부분 로그·보류 안내 Docker 재배포 — 2026-09-14

## 배포 결과

[부분 로그·보류 안내 보완](Partial_Input_and_Hold_Review_2026-09-14.md)을 기존 로컬 Docker 환경에 반영했다. API, 분석 worker, 모델 검증 worker, 웹 UI의 네 서비스를 교체했다. 운영서버 배포 기록은 아니다.

- UI: `http://127.0.0.1:18080`, API: `http://127.0.0.1:18000`.
- 실행 모드: `moduagent`. Production/Test 모두 기존 `gpt-5.4-mini` Primary를 유지하며 Verifier도 같은 프로필을 사용한다.
- 새 접수: `waf-judgment-v2.12/policy-2`, 입력 검사 `request-integrity-v2`. 관리자 편집 지침과 모델의 설정·검증 상태는 변경하지 않았다.
- 과거 접수의 고정 지침·입력 검사 버전은 유지한다. v2.12로 과거 판정을 덮어쓰지 않았다.
- DB는 기존 `0014_agent_configuration` 그대로이며 새 마이그레이션·운영 패키지 추가는 없다.

v2.11의 요청 의미 판단 지침과 v2.12의 제한적 부분 로그 검사가 함께 배포됐다. v2.11을 따로 실모델 평가한 것은 아니므로 이후 v2.10 대비 변화 전체를 부분 로그 검사 하나의 효과로 해석하면 안 된다.

## 보존과 검증

재배포 전 진행 중인 작업이 없음을 확인하고 SQLite backup API로 일관된 백업을 만들었다. 백업·비밀 설정은 비공개 `.local-deploy`와 기존 데이터 볼륨에 보관하며 Git에 포함하지 않는다. 데이터 복원·삭제·볼륨 초기화는 하지 않았다.

- 재배포 직후 **19개 테이블의 모든 기존 행이 일치**했다. 분석 **1,039건**과 모델·지침·키·리뷰·감사 이력을 보존했다.
- 암호화 값 **17,796개**의 복호화, DB 무결성·외래 키 검사를 통과했다. 본문과 키를 출력하지 않았다.
- 네 서비스 실행, API healthy, 검사 시 재시작 0회. 기존 환경값·포트·볼륨·네트워크·실행 명령 보존을 확인했다.
- API와 두 worker의 **소스 105개 파일**을 현재 작업 코드와 해시로 대조했다.
- **HTTP 22개 확인 통과**: 로그인·잘못된 Origin 거부·미인증 거부·설정·기존 테스트 결과/이력·PDF/Excel·운영 API 정의서 등을 확인했다. 웹 JS/CSS는 새 빌드 파일과 바이트 단위로 일치했다.
- **배포된 웹 화면 24개 확인 통과**: 12개 상태를 데스크톱 라이트·모바일 다크에서 검사했다. 해당 브라우저 검사는 API를 가짜 응답으로 대체하므로 실제 모델 검증과 구분한다.
- 선행 오프라인 검증은 백엔드 **1,907항목**, 프런트엔드 **402항목** 통과다. 상세 범위는 [구현 기록](Partial_Input_and_Hold_Review_2026-09-14.md#검증)에 있다.
- 게시용 임시 복제본에서도 백엔드 **1,907항목 재통과**(649.44초), 프런트엔드 **33개 테스트 파일 재통과**(9.05초)를 확인했다. 백엔드는 네트워크·운영 DB 없이 읽기 전용 소스와 임시 저장소로 검사했다. 기존 Starlette/AnyIO 사용 중단 예고 경고 1건이 남아 있다. 최초 임시 테스트 환경의 개발 패키지 누락을 기존 의존성 연결로 해결한 뒤 재실행했으며 앱·의존성 버전은 수정하지 않았다.

프런트엔드 빌드는 성공했으며 JS 518.21 kB의 묶음 크기 경고는 남아 있다. 이번에 코드 분할이나 운영 의존성 변경은 하지 않았다.

게시 전 비교에서 기존 로컬 관리자 비밀번호·세션 비밀값·데이터 암호화 키가 저장소에 이미 공개된 개발 기본값과 같음을 확인했다. 이번 요청에서는 기존 설정을 보존했다. 이 로컬 구성을 운영에 복사하지 않으며, 운영 신규 설치에서는 전용 비밀값을 생성해야 한다. 기존 DB의 암호화 키는 환경값만 교체하면 복호화가 실패하므로 백업과 키 전환 설계 없이 변경하지 않는다. 새 모델 API 키·비공개 환경 파일·DB는 게시 대상에서 제외한다.

## 재기동과 복구 주의

현재 전용 Compose 파일과 정확한 명령은 비공개 `.local-deploy/README.md`의 맨 위 기록을 따른다. 기본 Compose를 단독 실행하면 포트·모드·비밀값 기본값으로 바뀔 수 있다.

기존 이미지와 백업은 보존했다. 새 지침으로 접수한 분석이 있으므로 이전 이미지로 무조건 되돌리거나 과거 DB를 복원하지 않는다. 복구가 필요하면 현재 DB도 먼저 보존하고 새 실행과의 호환성을 검토한다. `down -v`는 사용하지 않는다.

## 실제 모델 평가

재배포 및 HTTP·화면 확인을 마친 뒤 기존 파싱 난이도·Hard·Medium 각 50건을 같은 `gpt-5.4-mini` 설정으로 접수했다. 파싱 50·Hard 50·Medium 42건이 완료됐고 Medium 8건은 OpenAI HTTP 429로 실패했다. 사용자 요청에 따라 추가 호출 없이 같은 완료 142문항만 이전 결과와 비교했다. 별도 18건과 실제 사내 로그는 이번 유료 실행에 포함하지 않았다. [전체 비교 보고서](evaluations/Partial_Hold_GPT54Mini_150_2026-09-14.md)에 제외 문항·지표·한계를 함께 남긴다.

평가 후 기존 1,039건 및 19개 테이블의 모든 기존 행을 보존했고 총 분석은 1,189건이다. 암호화 값 20,556개 복호화·DB 무결성 검사를 통과했다. 네 서비스는 여전히 실행 중이며 API healthy, 재시작 0회, API·두 worker 소스 105개 파일 일치를 다시 확인했다. 원래 작업 폴더의 Git 메타데이터가 비어 있어 GitHub main의 기존 이력을 별도 임시 복제본으로 받아 게시를 준비했으며 원래 `.git`이나 과거 이력을 덮어쓰지 않는다.
