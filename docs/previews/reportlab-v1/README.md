# ReportLab PDF 디자인 시안

2026-09-15 · 운영 반영 전 검토 자료

후속 검토를 반영한 [근거 그룹 카드형 시안](../reportlab-v2/README.md)이 추가되었다. 아래 파일과 검증 기록은 첫 시안의 이력으로 보존한다.

외부 다운로드와 브라우저 설치 없이 보고서 PDF를 만들 수 있는지 확인한 시안이다. 현재 프로젝트에 포함된 ReportLab 5.0.1과 NanumGothic 글꼴을 사용했다. 실제 API의 PDF 출력 방식, Dockerfile, 배포 설정, DB는 변경하지 않았다.

## 웹 보고서와의 관계

웹에서 사용하는 `buildAnalysisReport`와 `parseApiDocument`를 재사용해 같은 표시용 본문을 생성한다. 제목·문단·표의 값·발췌·근거 순서는 유지하고 PDF의 조판만 다르게 했다. 일반 키/값 표의 반복되는 `항목 / 내용` 헤더는 생략했다.

- 판정·심각도는 배경색과 흰색 글씨로 강조한다.
- 정탐 근거는 빨강, 오탐 근거는 초록, 참고 내용은 회청색 제목 띠로 나눈다. 색상 외에 제목을 함께 제공한다.
- 분석 개요와 소요 시간은 한 줄에 두 쌍의 항목·값을 배치한다. 항목을 삭제하거나 줄임표로 자르지 않는다.
- 긴 발췌는 줄바꿈과 페이지 나눔을 허용한다. HTML처럼 보이는 문자열도 실행하거나 태그로 해석하지 않는다.
- 한글 글꼴을 PDF 안에 포함하며 본문은 이미지가 아닌 검색·선택 가능한 텍스트다.

HTML/CSS를 그대로 변환하는 방식은 아니다. 웹과 색상·구조를 맞춘 별도 인쇄용 디자인이므로 글자 크기, 줄바꿈, 여백, 페이지 수는 다르다. 기존 웹 형식 참고 출력에는 현재 PDF용 번들과 페이지 설정을 사용했으며, 비교용 표시를 추가했다. 브라우저 버전과 비교용 표시 때문에 운영에서 저장한 파일과 바이트 단위로 같지는 않다.

## 검증 결과

- Python 3.12 / ReportLab 5.0.1의 기존 로컬 이미지에서 `--network none`으로 세 PDF 생성 성공. 새 패키지나 브라우저를 다운로드하지 않았다. 생성 시 브라우저 경로도 존재하지 않는 경로로 지정했다.
- 독립 프로토타입 테스트 **15개 통과**. 네트워크·하위 프로세스 호출 금지, 긴 문단·발췌·표 셀 나눔, 글꼴 포함, HTML 비실행, 입력·출력·쪽수 제한, 입력 불변 확인.
- 웹 보고서·표시·문서 파서의 기존 테스트 파일 **3개 통과**.
- Poppler 텍스트 추출로 각 시안의 **81 / 108 / 148개 텍스트 항목**이 유지됨을 확인했다. 레이아웃에 따른 공백·줄바꿈은 정규화하여 비교했다. 같은 값의 출현 횟수까지 검증하는 방식은 아니다.
- 추출된 모든 글자의 단어 경계가 페이지 여백 안에 있는지 확인했다.
- 총 **11쪽**을 이미지로 변환해 한글 표시, 텍스트 잘림, 페이지 나눔, 근거 구분을 육안 확인했다.
- 웹 형식 참고 자료는 이미 설치된 로컬 브라우저로 별도 생성했다. 페이지 네트워크 요청은 모두 차단했고 실제 서비스/API/DB에는 접근하지 않았다. 이 비교 도구는 ReportLab 생성에 필요하지 않다.

## 범위와 남은 확인

이번 작업은 시안 제작까지다. 실제 다운로드 엔드포인트는 아직 Chromium 방식을 사용하므로 현재 운영 이미지의 외부 다운로드 문제를 해결한 배포본은 아니다. Git 업로드와 재배포도 하지 않았다.

운영 적용 전에 다음을 확인한다.

1. 이 PDF 디자인에 대한 사용자 확인.
2. 기본 보고서 외에 디코딩 포함·부록 포함·이전 결과 호환성 검증. 이번 시안은 밝은 테마의 기본 보고서만 대상으로 한다.
3. 웹/PDF 본문의 동기화 방식 확정 후 기존 관리자 권한·감사 이력·원문 선택 범위·시간/크기 제한을 유지하며 출력기 교체.
4. Chromium 설치 단계와 불필요해진 브라우저 의존성 제거, 폐쇄망 반입용 이미지 생성 및 다운로드 기능 회귀 테스트.

현재 시안에는 기존 Chromium PDF의 접근성 태그와 문서 책갈피를 구현하지 않았다. 페이지에 걸친 근거에 그룹 제목을 반복 표시하는 기능도 후속 조판 개선 후보다. 글꼴에 없는 문자나 제어 문자는 `[U+XXXX]`로 표시하며 저장된 입력은 변경하지 않는다.
