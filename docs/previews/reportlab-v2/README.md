# 근거 그룹 카드형 PDF 시안

2026-09-15 · 승인 전 디자인 검토 기록

> 승인된 디자인은 이후 실제 PDF 다운로드에 적용했다. 현재 동작과 배포 기준은 [ReportLab PDF 안내](../../ReportLab_PDF_2026-09-15.md)를 따른다. 아래 검증·미반영 설명은 시안 작성 당시 기록이다.

사용자 검토를 반영한 두 번째 시안이다. 정탐 근거·오탐 근거·참고 내용을 그룹별 테두리로 묶되, 배경색은 제목 칸과 로그 발췌에만 적용했다. 근거 설명 영역은 흰색이다. 첫 번째 시안의 본문·판정·원문은 그대로 유지한다.

## 변경 내용

- 그룹 전체를 얇은 테두리와 왼쪽 색상선으로 묶는다.
- 제목 칸만 정탐은 옅은 빨강, 오탐은 옅은 초록, 참고 내용은 회청색 배경으로 표시한다.
- 근거 제목·위치·판단 이유는 흰색 바탕에 표시하고 로그 발췌 상자에만 옅은 회색 계열 배경을 넣는다.
- 같은 그룹의 근거 사이는 얇은 구분선으로 나눈다.
- 카드가 다음 페이지로 넘어가면 `정탐 근거 · 계속`처럼 그룹 제목을 반복한다. 같은 페이지에 작은 후속 카드를 다시 끼워 넣지 않는다.
- 한 페이지에 들어갈 크기의 근거는 발췌와 설명을 함께 넘긴다. 페이지보다 긴 근거만 내부에서 나눈다. 이에 따라 이전 시안보다 페이지 수가 늘어날 수 있다.

## 확인 결과와 적용 범위

독립 프로토타입 테스트 23개를 통과했다. 그룹 경계, 본문 불변, 제목 반복, 제목만 남는 페이지 방지, 제목 칸만 색상 적용, 긴 원문 분할, 네트워크·하위 프로세스 미사용 및 기존 크기 제한을 확인했다.

ReportLab 5.0.1의 기존 이미지에서 외부 통신을 차단하고 3개 PDF를 생성했다. 13쪽 전체의 본문 81 / 108 / 148개 텍스트 항목 보존과 페이지 경계를 자동 검사하고, 주요 근거·이어짐 페이지를 이미지로 확인했다. 본문 비교는 레이아웃 공백·줄바꿈과 반복되는 페이지 장식을 제외한 기준이다.

현재 변경은 [시안 도구](../../../scripts/reportlab_preview/README.md)와 검토 자료에 한정한다. 웹 UI·운영 PDF 엔드포인트·Dockerfile·DB·모델·저장 결과는 변경하지 않았고, 재배포·Git 업로드·실제 모델 호출도 하지 않았다. 기본 밝은 테마 외의 운영 적용 전 검증 범위는 [첫 시안의 남은 확인 사항](../reportlab-v1/README.md#범위와-남은-확인)을 따른다. 그룹 제목 반복은 이번에 시안에 구현했으며 접근성 태그·책갈피는 여전히 미구현이다.
