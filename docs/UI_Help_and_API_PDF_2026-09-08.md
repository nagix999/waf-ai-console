# 도움말 정리·운영 API 정의서 PDF — 2026-09-08

## 변경 범위

- 로그인, 대시보드, 분석 목록·상세, 테스트, 보고서, 원문·디코딩·Agent 이력, 설정의 세부 창까지 `?`를 검토했다.
- 제목이나 버튼을 반복하는 도움말은 제거했다. 페이지 소개는 제목 아래 작은 회색 문장으로, 파일 형식·처리 시간·필터 범위·모델 지정 조건·보고서 부록 범위는 해당 영역의 짧은 텍스트로 표시한다.
- 평가 지표의 정의·분모·높고 낮을 때의 의미, 모델 신뢰도의 한계, 입력 스키마 제한, 답안 연결 규칙, 민감한 원문 취급 등 해석이 필요한 설명만 `?`로 유지한다. 키보드 포커스·마우스·터치 동작을 유지했다.
- 주요 판정 요약의 줄 수 제한을 제거했다. 목록의 짧은 미리보기는 분석 상세에서 전체를 확인한다. 원문은 줄바꿈·복사 과정에서 변경하지 않는다.
- 운영 API 정의서는 현재 적용한 입력 스키마를 포함하는 **전체 PDF**로 내려받는다. 선택한 항목이나 검색 결과만 출력하지 않는다.
- 정의서 12개 항목의 본문 아래에 `← 이전 항목 제목` / `다음 항목 제목 →` 버튼을 제공한다. 이동하면 새 제목으로 스크롤·키보드 포커스를 옮긴다. 검색 중에는 검색된 항목 사이에서 이동하며 마지막 항목에서 처음으로 순환하지 않는다.

## PDF 계약

`GET /api/v1/production-api.pdf`는 기존 JSON 정의서와 같은 생성 원본·현재 활성 스키마를 사용한다. 관리자 세션 또는 `ingest` 권한이 필요하다.

웹 UI는 조회 당시 스키마의 `expected_schema_version_id`와 `expected_schema_hash`를 함께 전달한다. 그 사이 활성 스키마가 달라졌으면 409를 반환하고 새로고침 후 명시적으로 다시 내려받도록 안내한다. 문서를 열거나 항목을 이동할 때 PDF를 미리 생성하지 않는다.

한글 글꼴을 포함하는 서버 생성 PDF이며 외부 리소스를 읽거나 예제 API를 실행하지 않는다. 성공 응답은 `application/pdf`, 첨부 파일, `no-store`이다. 과도한 문서는 413, 생성 불가는 503으로 처리하고 부분 파일이나 내부 오류 내용을 반환하지 않는다. 본문 512,000바이트·12,000줄·5,000블록·표 12열·100페이지·파일 10 MiB를 넘기지 않는다.

기존 ReportLab과 패키지 내 한글 글꼴을 재사용한다. 새 운영 의존성·DB 마이그레이션·LLM 호출·프롬프트 변경은 없다.
