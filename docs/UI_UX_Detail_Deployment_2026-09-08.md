긴 설명은 `?`의 마우스·키보드 포커스·터치 도움말로 제공한다. 실제 기록·편집·미리보기는 명시적인 버튼/창으로 열며 설명용 펼치기와 브라우저 기본 prompt/confirm은 제거했다. 삭제·외부 전송·비용 등 행동 전 경고를 도움말에만 숨기지 않는다.

고정 화면의 ‘합성’ 표시는 사용하지 않는다. 기존 사용자가 저장한 테스트명·답안 출처·원문·보고서는 일괄 치환하지 않는다. 예시를 실제 폼 값으로 자동 입력하지 않으며 모델 기본 설정과 저장된 정의는 유지한다.

## 원문·기록의 보존 원칙

- 검색은 대소문자를 구분하는 문자열 검색이며 처음 200개 일치 위치까지 이동한다. 제한 도달을 표시한다. 정규식 실행·자동 정규화·외부 전송·브라우저 저장을 하지 않는다.
- 검색·줄바꿈은 표시 상태만 바꾸며 원문/JSON 복사는 전체 표시 문자열을 복사한다. 원문 CRLF는 보존한다. 짧은 디코딩 조각에는 복사 중심의 간결한 도구를 사용한다.
- 디코딩의 제어문자는 읽기 위한 표시로 바뀔 수 있다. 디코딩 화면의 복사가 저장된 HTTP 전체 원문 복사와 다름을 안내한다. 과거 모델이 이 조회 시점의 후보를 사용한 것으로 표시하지 않는다.
- 원문과 Agent 입력은 기존 관리자·감사 조회 정책을 유지하고 필요한 화면을 열 때 읽는다. 실행 시간의 미측정과 실제 0ms를 구분한다.
- 기존 최종 판정, 근거, 참고 답안·평가 분모, 암호화 이력을 재작성하지 않는다. 필드 정의는 계속 실행 이력에만 기록하며 LLM 입력에 새로 추가하지 않는다.
- PDF/Excel은 분석 상세 보고서 중심이다. HTTP 전체 원문·Agent 입출력·기술 부록은 제외하지만 근거 발췌에도 민감 정보가 있을 수 있으므로 다운로드 전 보관·반출 주의를 표시한다.

빌드 및 복사 DB 마이그레이션 리허설 후 대기/실행 작업이 없음을 확인하고 기존 네 서비스를 중지했다. 중지된 실제 DB의 일관된 백업을 만든 다음 네트워크가 없는 전용 컨테이너에서 Alembic을 실행했다. 기존 컬럼의 모든 행과 암호화 값을 비교한 후 API 정상 상태를 확인하면서 서비스를 시작했다.

신규 보고서 의존성은 ReportLab 5.0.1, Pillow 12.3.0, charset-normalizer 3.5.1이며 NanumGothic 일반/굵게 글꼴과 OFL을 포함한다. 기존 설치 패키지 버전은 유지했다. 외부 문서 변환 서비스·글꼴 다운로드·새 프런트엔드 패키지는 추가하지 않았다.

브라우저 회귀는 Chromium에서 390px 좁은 화면·다크 모드·키보드·중첩 창·초안 보존·이중 클릭·뒤로/앞으로 이동을 확인했다. 실제 배포의 HTML/CSS/JS는 최종 빌드 파일과 바이트 단위로 일치한다. 임시 개발 서버는 종료했다.

실제 비모의 완료 분석의 PDF/XLSX를 다운로드해 PDF 한글 글꼴, 최종 판정 일치, Excel 문자열 셀·수식/외부 관계 차단, 관리자 접근 및 감사 기록을 확인했다. 실제 서비스의 분석 접수·재실행·설정 변경은 하지 않았고 문서 본문을 검증 로그에 남기지 않았다.

검증 과정에서 발견한 테스트 환경 문제도 구분한다. 초기 백엔드 PDF 테스트는 테스트 컨테이너의 noexec 임시 디렉터리에 설치한 네이티브 의존성 때문에 실패했으며 실행 가능한 테스트 전용 경로로 바꾼 뒤 전체 통과했다. 실제 HTTP 스크립트의 첫 실행은 빈 query를 엄격 파싱하는 검사 코드 오류로 요청 전에 중단됐으며 검사 코드만 고친 후 130개가 통과했다. 첫 실패 증적은 보존했다.

## 아직 검증하지 않은 부분

- 실제 분석가와의 사용성 평가와 업무 시간 단축 효과.
- 실제 LLM 재실행·유료 호출·판정 품질 및 운영 GPU/Gemma 모델 성능. 과거 설정이 없는 실패를 현재 모델로 대체해 실행하지 않는다.
- 다중 동시 보고서 생성 부하, 실제 Microsoft Excel 및 모든 PDF 뷰어, Chromium 이외 브라우저의 전체 호환성.

이번 작업은 새 프롬프트·판정 정책·외부 조사 도구를 추가하거나 활성 설정을 변경하는 작업이 아니다. 배포된 UI에서의 기능 동작 검증과 모델 품질 검증을 구분한다.
