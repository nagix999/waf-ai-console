## 주요 회귀

- 서비스 키 원문 1회 반환·화면 소거·해시 저장, source 격리, ingest/review 최소 권한, 관리자 세션 우선, 이름 수정·폐기·마지막 인증 시각.
- 과거 환경변수와 개발 기본 키가 남아 있어도 인증 401. 관리자 로그인과 새 DB 발급 키는 정상. API/화면/공개 Compose 설정에서 bootstrap 경로 제거.
- 발급 응답 유실 시 자동 재발급 금지, 원문 반환 후 목록 조회 실패에도 원문 보존, 닫기·탭 이동 시 원문 제거, 폐기 확인.
- 테스트 업로드의 expected_verdict를 원문·fingerprint·Primary/Verifier 입력에서 분리. 같은 트랜잭션의 답안 연결, 같은 답안 유지·다른 답안 충돌, Production/직접 입력의 답안 혼입 거부.
