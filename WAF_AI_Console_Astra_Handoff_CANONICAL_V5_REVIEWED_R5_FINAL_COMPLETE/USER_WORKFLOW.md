# 사용자 중심 사용 흐름 — R5 FINAL

사용자가 기억해야 하는 흐름은 하나다.

```text
정답 데이터 준비
→ 테스트
→ 결과 확인
→ 필요한 것 수정
→ 운영 반영 검토
→ 운영에 반영
→ 운영 확인
```

English:

```text
Prepare Ground Truth
→ Run a Test
→ Review Results
→ Fix What Is Needed
→ Production Review
→ Apply to Production
→ Observe Production
```

## 역할이 겹치지 않는 메뉴

### 평가 > 테스트

```text
테스트 생성
Test Run 비교
문항 결과
평가 상세
이 설정으로 다시 테스트
테스트 사례를 정답 데이터에 추가
운영 반영 검토
```

### 운영 > 분석 이력

```text
운영 목적으로 처리된 분석만
검색
필터
개별 분석 조사
```

테스트 분석은 운영 목록에 다시 나타나지 않는다.

Global Search에서 Test Analysis를 찾으면 해당 Test/Case로 이동한다.

## 처음 사용할 때

```text
홈
→ 모델 연결
→ 기본 테스트 설정
→ 정답 데이터 공식 버전 만들기
→ 공식 테스트
→ 운영 반영 검토
→ 운영에 반영
```

## 평소 반복 작업

```text
테스트 결과 확인
→ 설정 또는 정답 데이터 수정
→ 이 설정으로 다시 테스트
→ 평가 상세 확인
→ 운영 반영 검토
→ 운영에 반영
```

## 테스트 결과를 정답 데이터로 재사용

```text
테스트
→ 테스트 사례를 정답 데이터에 추가
→ 새 데이터셋 또는 기존 데이터셋
→ 미리보기
→ 중복/충돌/정답 없음 확인
→ 편집 중 데이터에 추가
→ 필요한 항목만 수정
→ 공식 버전 만들기
```

심층 판정은 자동으로 정답이 되지 않는다.
