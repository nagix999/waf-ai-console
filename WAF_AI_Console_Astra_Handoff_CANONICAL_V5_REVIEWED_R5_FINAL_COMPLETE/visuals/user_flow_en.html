WAF AI Console workflow

This is the only lifecycle users need to remember.

1
Prepare Ground Truth

Prepare reference cases and publish a version for evaluation.

↓
2
Run a Test

Load defaults and run an Official or Development Test.

↓
3
Review Results

Focus on mismatches, inconclusive cases, and failures.

↓
4
Fix What Is Needed

Update configuration or Ground Truth when necessary.

↓
5
Production Review

Compare current Production with the tested configuration and review readiness.

↓
6
Apply to Production

Apply the exact tested configuration to Production.

↓
7
Observe Production

Review inference history and runtime status.

↺ If something needs improvement, run another test
